04

AI/NLP · Tech Stack

Transformer Encoder 기반 광고성 리뷰 분류

광고성 리뷰는 특정 단어 하나보다 문체, 표현 방식, 문맥 흐름의 차이가 크다고 판단했습니다.

TF-IDF는 단어 빈도, Word2Vec은 단어 의미, BERT/ELECTRA는 문장 문맥 이해에 강점이 있어 한국어 블로그 리뷰 분류에 적합한 모델을 검토했습니다.

BERT/ELECTRA 모델 비교와 실험 기반 선정

KcBERT와 KcELECTRA를 비교하고, 블로그처럼 구어체·신조어·비정형 표현이 많은 한국어 리뷰 데이터에 맞는 사전학습 모델을 검토했습니다.

모델, 데이터셋 방식, 하이퍼파라미터를 바꿔 Accuracy, Precision, Recall, F1-score, AUC, Latency, Model Size를 함께 비교했습니다.

모델 개선과 서비스 적용 기준

광고 리뷰를 놓치지 않는 것이 중요해 Recall을 중요 기준으로 보고, 불균형 데이터 특성상 F1-score도 함께 확인했습니다.

2차 개선에서는 데이터 편중과 가게명 노이즈를 진단하고, 데이터 재구성·가게명 마스킹·제목+본문 병합·임계값 최적화·SHAP 분석으로 개선 방향을 도출했습니다.

서비스 적용 관점에서는 OpenVINO INT8 양자화로 모델 크기와 추론 효율을 함께 고려했습니다. 모델 크기를 약 416MB에서 106MB 수준으로 줄이면서 정확도 손실은 거의 없었습니다.
Frontend: Flutter, React · Backend: FastAPI · DB/Auth: Supabase · Map/LBS: Kakao Map · External Review: Naver Blog API · Deployment: Vercel 설정 확인
